# Proof Step Checking in a Constraint Programming Unsatisfiability Proof Checker

This is my thesis, written for my MSc Computer Science at TU Delft, finished in 2025. The thesis project was awarded with a 9/10.

- Submitted version: [`thesis_tmtenbrink_proof_checking_cp.pdf`](thesis_tmtenbrink_proof_checking_cp.pdf)
- TU Delft repository URL: https://resolver.tudelft.nl/uuid:02c7b3fe-73ce-4837-adf0-5ba015311a0a
- Supervisor: Emir Demirović 

The work in this thesis contributed to the work described in [Formally Verified Certification of Constraint Programming Proofs](https://doi.org/10.4230/LIPIcs.CP.2026.24) (Flippo, Sidorov, ten Brink, Pit-Claudel and Demirović, CP 2026).

This branch contains the Typst source (`src`) of the submitted version. The `final` and `greenlight` branches contain earlier versions.

The actual proofs live in [https://github.com/ConSol-Lab/fzn-drcp-check].
