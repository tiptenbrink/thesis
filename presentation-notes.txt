# Thesis Defense Presentation Notes

## TEXT SIZE SYSTEM (6 SIZES):
- **text-present-xs** (1vw): Minimal details, footnotes
- **text-present-small** (1.5vw): Supporting details, captions  
- **text-present** (2vw): Body text, standard content
- **text-present-large** (2.5vw): Section headers, important content
- **text-present-xl** (3vw): Slide titles, major headings
- **text-present-hero** (4vw): Special emphasis, title components

## SEMANTIC COLOR SYSTEM (TU Delft Brand Colors):
- **koningsblauw** (blue): "Proof" and "Checking" semantic connection - use for proof/verification concepts
- **paars** (purple): "Step" semantic connection - use for individual steps, methodology concepts
- **bosgroen** (green): "Constraint Programming" semantic connection
- **bordeaux** (red): "Unsatisfiability", problems, gaps
- **donkergrijs-muted** (gray): De-emphasized content
- All colors have -muted variants for reduced emphasis

**CRITICAL RULE**: Always use semantic colors that match the title slide concepts. When referring to proof checking → use koningsblauw, when referring to steps → use paars, etc.

## CRITICAL DESIGN PRINCIPLES:
- **1.7:1 aspect ratio** - extremely limited vertical space
- **p-4 to p-6 padding maximum** - no larger
- **space-y-4 max spacing** - tighter is better
- **Only use global variables** - never text-xl, text-3xl etc.
