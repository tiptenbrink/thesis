# Thesis Defense Presentation Notes - Current Version

## Actual Structure (12 slides, current implementation)

### 1. Title Slide (1 animation)
- Full thesis title: "Proof Step Checking in a Constraint Programming Unsatisfiability Proof Checker"
- Name: Tip ten Brink
- Supervisor: E. Demirović

### 2. Motivation (3 animations)
- Modern solvers tackle complex problems at incredible speed
- Challenge: When solver says "impossible" - how do we know it's right?
- Solution: Proof-based verification (solvers explain their reasoning)

### 3. CP Challenge (3 animations)  
- SAT solvers use proof logging successfully (competition standard since 2013)
- CP Gap: No native proof checking (current approach: translate to simpler formats)
- Our Vision: Direct CP verification with formal guarantees

### 4. Research Question (2 animations)
- Main question: "How can we build formally verified checkers for individual proof steps?"
- Focus: Individual proof steps, Two constraints (Alldifferent • Cumulative)
- Approach: Machine-checked proofs using Rocq theorem prover

### 5. Methodology (3 animations)
- **Flow diagram**: Study propagation algorithm → Identify conflict types → Build checker
- **Key Insight**: Checking conflicts is easier than checking specific propagations
- **Systematic Process**: Reusable for any constraint, Extensible framework

### 6. Perforated Intervals (3 animations)
- **The Problem**: How to represent complex variable domains efficiently?
- **Our Solution**: [bounds] + {holes} - efficient representation for sparse domains
- **Tightness Theory**: Formal conditions for when operations are efficient
- **Applications**: Domain tracking, foundation for domain maps, constraint reasoning
- **Example**: [1, 10] \ {3, 7, 8} represents {1, 2, 4, 5, 6, 9, 10}

### 7. Deduction Checker (2 animations)
- Combines multiple facts into new conclusions
- Uses domain maps built on perforated intervals
- Achievement: Formalized in Rocq

### 8. Alldifferent Checker (3 animations)
- All variables must have distinct values (scheduling, assignments, puzzles)
- **Key Tool**: Hall's theorem provides theoretical foundation
- **Complete verification**: Catches all valid propagations

### 9. Cumulative Checker (2 animations)
- Resource capacity constraints over time (never exceed available capacity)
- **Method**: Timetable reasoning
- **Result**: Demonstrates methodology on complex constraints
- FIGURE: Resource timeline

### 10. Achievements (3 animations)
- **Theoretical Foundation**: Perforated intervals • Systematic methodology • Conflict types
- **Implementation**: Three checkers (Deduction/Domain maps, Alldifferent/Hall's theorem, Cumulative/Timetable reasoning)  
- **Formally Verified in Rocq**: Machine-checked correctness proofs
- **Main Result**: Complete systematic approach to CP-native proof checking

### 11. Future Work (2 animations)
- **Current Challenge**: High verification effort for each constraint
- **Next Steps**: Verification automation, Performance improvements, More constraints
- **Big Opportunity**: Richer proof hints (guide checkers efficiently)

### 12. Summary (2 animations)
- **Main Achievement**: Systematic Foundation for CP-Native Proof Checking
- **Complete**: Theoretical framework + working implementations + formal verification
- **Three Pillars**:
